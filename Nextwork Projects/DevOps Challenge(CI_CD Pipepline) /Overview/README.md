### What is DevOps?

DevOps is a set of practices that involves the development and operations team working together or a single individual to build, test, deploy and maintain a reliable application, while reducing the it's development lifecyle. DevOps engineers implement the DevOps practices in their organizations buy utilizing tools with can build automated pipelines, containerize and turn cloud infrastructure to code.

### What is CI/CD?

CI/CD stands for Continuous Integration and Continuous Delivery/Deployment. This process helps teams by significantly reducing the manual work need in the application pipeline. Developers can automate the entire application development lifecycle whenever a change is made to the code, making it more efficient and reliable.
